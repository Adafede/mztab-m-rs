# mztab-m-rs

Read, write, validate, and convert
[mzTab-M](https://github.com/HUPO-PSI/mzTab-M) files: the HUPO-PSI / MSI
exchange format for mass-spectrometry-based metabolomics results.

- **Try it now (no install):** [Live Browser Demo](demo/index.html) — runs
  locally in WebAssembly; files never leave your computer.
- **Validation codes:** [Validation Findings Reference](findings.md) — every
  `MZT-*` code with severity, meaning, and pinned spec anchor.
- **Rust API:** [`mztab-m`](api/mztab_m/index.html) |
  [`mztab-m-obo`](api/mztab_m_obo/index.html) |
  [`mztab-m-api`](api/mztab_m_api/index.html) |
  [`mztab-m-cli`](api/mztab_m_cli/index.html)
